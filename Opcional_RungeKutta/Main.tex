\begin{abstract}
En este trabajo se presenta una simulación del péndulo doble utilizando el algoritmo de Runge-Kutta para resolver las ecuaciones de movimiento del sistema. Se analizan diferentes aspectos del comportamiento del péndulo doble, como la evolución de los ángulos frente al tiempo, la representación del espacio fasorial, las secciones de Poincaré, el diagrama de bifurcación y el diagrama de Lyapunov. Los resultados obtenidos muestran claramente el comportamiento caótico del sistema, especialmente a energías más altas, donde pequeñas diferencias en las condiciones iniciales pueden llevar a resultados muy diferentes a largo plazo.
\end{abstract}

\section{Introducción}

Un péndulo doble es un sistema dinámico que consiste en dos masas conectadas por varillas rígidas, donde una masa cuelga de la otra. Este sistema exhibe un comportamiento caótico, lo que significa que pequeñas diferencias en las condiciones iniciales pueden llevar a resultados muy diferentes a largo plazo. Para simular el movimiento del péndulo doble, se utilizan las ecuaciones de movimiento derivadas de las ecuaciones de Euler-Lagrange y se resuelven numéricamente utilizando el algoritmo de Runge-Kutta.

\section{Metodología}

En este apartado se describirá el proceso de derivación de las ecuaciones de movimiento para el péndulo doble, así como la implementación del método de Runge-Kutta para resolver estas ecuaciones numéricamente.

Para ello, definimos las coordenadas generalizadas del sistema, que son los ángulos $\theta_1$ y $\theta_2$ que forman las varillas con la vertical. Si denotamos las masas como $m_1$ y $m_2$, las longitudes de las varillas como $l_1$ y $l_2$, y la aceleración debida a la gravedad como $g$, las ecuaciones de movimiento para el péndulo doble se pueden escribir como:


\begin{align}
        T = \frac{1}{2} (m_1+m_2) l_1^2 \dot{\theta}_1^2 + \frac{1}{2} m_2  l_2^2 \dot{\theta}_2^2 + m_2l_1 l_2 \dot{\theta}_1 \dot{\theta}_2 \cos(\theta_1 - \theta_2) \\
         V = -(m_1+m_2) g l_1 \cos(\theta_1) - m_2 g l_2 \cos(\theta_2) \\
        \mathcal{L} = T - V 
\end{align}




Aplicando las ecuaciones de Euler-Lagrange:

\begin{equation}
\dfrac{d}{dt} \left( \dfrac{\partial \mathcal{L}}{\partial \dot{\theta}_i} \right) - \dfrac{\partial \mathcal{L}}{\partial \theta_i} = 0
\end{equation} \footnote{La explicación de las ecuaciones se expone en el apéndice.}

Si aplicamos las ecuaciones de Euler-Lagrange a las coordenadas generalizadas $\theta_1$ y $\theta_2$, obtenemos unas expresiones en las que se relacionan las aceleraciones angulares $\ddot{\theta}_1$ y $\ddot{\theta}_2$ con las posiciones angulares $\theta_1$ y $\theta_2$, así como con sus velocidades angulares $\dot{\theta}_1$ y $\dot{\theta}_2$. Estas ecuaciones son no lineales y acopladas. 

El problema con el que nos encontramos es que para aplicar el método de Runge-Kutta necesitamos transformar las ecuaciones de segundo orden en un sistema de ecuaciones de primer orden\footnote{El porqué de transformarlas se explica en el apéndice.}.

Para lograr esto, definimos nuevas variables para representar las velocidades angulares:

\begin{align}
\omega_1 = \dot{\theta}_1 \\
\omega_2 = \dot{\theta}_2
\end{align}

 
Con estas nuevas variables, podemos reescribir las ecuaciones de movimiento como un sistema de cuatro ecuaciones de primer orden:

\begin{align}
\dot{\theta}_1 = \omega_1 \\
\dot{\theta}_2 = \omega_2 \\
\dot{\omega}_1 = f_1(\theta_1, \theta_2, \omega_1, \omega_2) \\
\dot{\omega}_2 = f_2(\theta_1, \theta_2, \omega_1, \omega_2)
\end{align}

Donde $f_1$ y $f_2$ son funciones que dependen de las posiciones y velocidades angulares, así como de los parámetros del sistema (masas, longitudes, gravedad).


La forma de las funciones $f_1$ y $f_2$ es la siguiente:
\begin{align}
f_1(\theta_1, \theta_2, \omega_1, \omega_2) = \dfrac{m_2 l_1 \omega_1^2 \sin(2(\theta_1 - \theta_2)) + 2 m_2 l_2 \omega_2^2 \sin(\theta_1-\theta_2) + 2\,g m_2\cos(\theta_2)\sin(\theta_1-\theta_2) + 2gm_1\sin(\theta_1)}{-2\, l_1 (m_1 + m_2\sin^2(\theta_1 - \theta_2))} \\[6pt]
f_2(\theta_1, \theta_2, \omega_1, \omega_2) = \dfrac{m_2 l_2 \omega_2^2 \sin(2(\theta_1 - \theta_2)) +2(m_1 + m_2)l_1 \omega_1 ^2\sin(\theta_1 - \theta_2) +2g(m_1 + m_2)\cos(\theta_1)\sin(\theta_1 - \theta_2)}{2\ l_2 (m_1 + m_2\sin^2(\theta_1 - \theta_2))}
\end{align}


Una vez que tenemos el sistema de ecuaciones de primer orden, podemos aplicar el método de Runge-Kutta para resolverlo numéricamente. El método de Runge-Kutta es un método iterativo que nos permite aproximar la solución de un sistema de ecuaciones diferenciales ordinarias. Para ello, necesitamos definir un paso de tiempo $h$ y un número de iteraciones $N$, y luego aplicar el algoritmo de Runge-Kutta para actualizar las variables $\theta_1$, $\theta_2$, $\omega_1$ y $\omega_2$ en cada iteración.


Para mantener la coherencia de las medidas, tomaremos los siguientes valores para los parámetros del sistema:
\begin{itemize}
\item $m_1 = 3$ kg
\item $m_2 = 1$ kg
\item $l_1 = 2$ m
\item $l_2 = 1$ m
\item $g = 1$ m/s²
\end{itemize}

Con esto podemos fijar las condiciones iniciales para la simulación. Por ejemplo, podríamos elegir fijar los valores de $\theta_1$ o $\theta_2$ y alguna de sus velocidades angulares $\omega_1$ o $\omega_2$, pero, si observamos la forma que tienen las ecuaciones de movimiento, podemos ver que el sistema no tiene una dependencia explícita con el tiempo, lo que significa que el sistema es conservativo y $T + V = \text{constante} = E$, siendo $E$ la energía total del sistema. Con esta ecuación de ligadura podemos fijar tres de las cuatro condiciones iniciales y la cuarta se fijará automáticamente a través de la ecuación de ligadura. 

Para las primeras tareas de la simulación, fijaremos $\theta_2$, $\omega_1$ y $\omega_2$ y calcularemos $\theta_1$ a través de la energía total del sistema. Para las siguientes tareas, fijaremos $\theta_1$, $\theta_2$ y $\omega_2$ y calcularemos $\omega_1$ a través de la energía total del sistema.



\subsection{Implementación Computacional}

Para implementar la simulación del péndulo doble seguimos los siguientes pasos:

\begin{itemize}
\item Derivamos las ecuaciones de movimiento utilizando las ecuaciones de Euler-Lagrange.
\item Transformamos las ecuaciones de segundo orden en un sistema de ecuaciones de primer orden.
\item Escogemos las condiciones iniciales y los parámetros del sistema.
\item Implementamos el método de Runge-Kutta de cuarto orden para resolver el sistema de ecuaciones de primer orden.
\item Ejecutamos la simulación y analizamos los resultados obtenidos.
\end{itemize}

El método de Runge-Kutta de cuarto orden es un método iterativo que puede describirse mediante el siguiente algoritmo:
    
\begin{algorithm}[H]
\SetAlgoLined
\KwResult{Aproximación de la solución del sistema de ecuaciones diferenciales ordinarias.}
\KwData{Sistema de ecuaciones de primer orden, condiciones iniciales, paso de tiempo.}
\For{n = 0 to N-1}{
    $k_1 = f(t_n, y_n)$\;
    $k_2^n = f(t_n + \frac{h}{2}, y_n + \frac{h}{2} k_1^n)$\;
    $k_3^n = f(t_n + \frac{h}{2}, y_n + \frac{h}{2} k_2^n)$\;
    $k_4^n = f(t_n + h, y_n + h k_3^n)$\;
    $y_{n+1} = y_n + \frac{h}{6} (k_1^n + 2k_2^n + 2k_3^n + k_4^n)$\;
    $t_{n+1} = t_n + h$\;
}
\caption{Algoritmo de Runge-Kutta de cuarto orden.}
\end{algorithm}

En nuestro programa de Fortran, implementamos este algoritmo mediante un bucle que itera sobre el número de pasos de tiempo y una subrutina que calcula las funciones para obtener los valores de $k_1$, $k_2$, $k_3$ y $k_4$ en cada iteración. Se adjunta una imagen de la subrutina a continuación:

\begin{figure}[H]
    \centering{
    \includegraphics[width=0.8\linewidth]{Image/Code/Subrutina.png}}
    \caption{Subrutina que calcula las funciones para el método de Runge-Kutta.}
    \label{fig:subrutina}
\end{figure}


Los valores de los parámetros para llevar a cabo la simulación computacional son los siguientes:

\begin{itemize}
\item Paso de tiempo $h = 0.001$ s
\item Número de iteraciones variable.\footnote{Debido al gran número de operaciones a realizar se varió el número de iteraciones para obtener los resultados deseados sin sacrificar una gran cantidad de tiempo.}
\item  Energías totales del sistema: $E_1 = -9.0$, $E_2 = -7.0$, $E_3 = 7.0$ y $E_4 = 9.0$.
\end{itemize}
Cuando tratemos con las energías, realizaremos una ligera modificación en estos valores, sumándole o restándolo $0.01$, para poder observar el comportamiento del sistema con condiciones iniciales muy cercanas entre sí, lo que nos permitirá observar claramente el comportamiento caótico del sistema.

    
\section{Resultados}
Para analizar el comportamiento del péndulo doble, realizamos varias simulaciones con diferentes condiciones iniciales y parámetros del sistema. Para ello realizamos cinco tareas distintas, cada una enfocada en un aspecto particular del comportamiento del sistema dinámico. 

Debido a la gran cantidad de resultados obtenidos, se han seleccionado algunos de los más representativos para cada tarea, con el fin de ilustrar claramente los diferentes comportamientos del sistema, aunque todos los resultados obtenidos se pueden encontrar en el repositorio de GitHub asociado a este proyecto\footnote{\url{https://github.com/WetZap/Propuestos_Computacional/tree/main/Opcional_RungeKutta}}.

\subsection{Ecuaciones Euler-Lagrange}

Las ecuaciones de Euler-Lagrange son un conjunto de ecuaciones diferenciales que describen el movimiento de un sistema dinámico a partir de su función Lagrangiana, que es la diferencia entre la energía cinética y la energía potencial del sistema. Para un sistema con coordenadas generalizadas $q_i$ y velocidades generalizadas $\dot{q}_i$, las ecuaciones de Euler-Lagrange se pueden escribir como:
\begin{equation}
\dfrac{d}{dt} \left( \dfrac{\partial \mathcal{L}}{\partial \dot{q}_i} \right) - \dfrac{\partial \mathcal{L}}{\partial q_i} = 0
\end{equation}

Donde $\mathcal{L}$ es la función Lagrangiana del sistema, que se define como $\mathcal{L} = T - V$, siendo $T$ la energía cinética y $V$ la energía potencial del sistema. Estas ecuaciones nos permiten derivar las ecuaciones de movimiento para el sistema dinámico a partir de su función Lagrangiana. Estas ecuaciones son fundamentales para el análisis de sistemas dinámicos y se utilizan ampliamente en la física teórica y la mecánica clásica.

Fueron obtenidas por el matemático suizo Leonhard Euler y el matemático francés Joseph-Louis Lagrange en el siglo XVIII, y han sido una herramienta fundamental para el estudio de la mecánica clásica y la física teórica desde entonces, permitiendo describir el movimiento de sistemas dinámicos de manera más general y elegante que las leyes de Newton.



\subsection{Condiciones necesarias para aplicar el método de Runge-Kutta}

El método de Runge-Kutta, en su formulación estándar, está diseñado para resolver ecuaciones diferenciales ordinarias de \textbf{primer orden} de la forma:
\begin{equation}
    \frac{dy}{dt} = f(t, y), \quad y(t_0) = y_0.
\end{equation}
Las ecuaciones de movimiento del péndulo doble, obtenidas a través del formalismo de Euler-Lagrange, son ecuaciones de \textbf{segundo orden} en $\theta_1$ y $\theta_2$. Para poder aplicar el método de Runge-Kutta, es necesario transformar dichas ecuaciones en un sistema equivalente de ecuaciones de primer orden.

Dada una ecuación diferencial de segundo orden general:
\begin{equation}
    \ddot{y} = f(t, y, \dot{y}),
\end{equation}
se introduce la variable auxiliar $\omega = \dot{y}$, lo que permite reescribir la ecuación original como el sistema de primer orden:
\begin{align}
    \dot{y} &= \omega, \\
    \dot{\omega} &= f(t, y, \omega).
\end{align}
Este procedimiento se generaliza a cualquier orden: una ecuación diferencial de orden $n$ se transforma en un sistema de $n$ ecuaciones de primer orden. Aplicado al péndulo doble, con dos ecuaciones de segundo orden en $\theta_1$ y $\theta_2$, se obtiene el sistema de cuatro ecuaciones de primer orden presentado en la sección de Metodología.

\subsection{Desarrollo matemático del método de Runge-Kutta de cuarto orden}

\subsubsection*{Método de Euler y su limitación}

El método numérico más sencillo para resolver $\dot{y} = f(t,y)$ es el \textbf{método de Euler}, que se obtiene truncando el desarrollo en serie de Taylor de $y(t+h)$ al primer orden:
\begin{equation}
    y(t+h) = y(t) + h\,y'(t) + \frac{h^2}{2}\,y''(t) + \cdots \approx y(t) + h\,f(t,y(t)).
\end{equation}
El error local de truncación es $\mathcal{O}(h^2)$, y el error global acumulado es $\mathcal{O}(h)$: el método de Euler es de \textbf{primer orden}. Para problemas físicos que requieren una integración precisa a lo largo de tiempos prolongados, este orden de precisión resulta insuficiente.

\subsubsection*{Idea general de los métodos de Runge-Kutta}

La serie de Taylor completa es:
\begin{equation}
    y(t_n+h) = y_n + h\,y'_n + \frac{h^2}{2!}\,y''_n + \frac{h^3}{3!}\,y'''_n + \frac{h^4}{4!}\,y^{(4)}_n + \mathcal{O}(h^5),
\end{equation}
donde las derivadas superiores de $y$ se expresan en términos de derivadas parciales de $f(t,y)$. Denotando $f_t = \partial f/\partial t$ y $f_y = \partial f/\partial y$:
\begin{align}
    y' &= f, \label{eq:d1}\\
    y'' &= f_t + f\,f_y, \label{eq:d2}\\
    y''' &= f_{tt} + 2f\,f_{ty} + f^2\!f_{yy} + f_y(f_t + f\,f_y). \label{eq:d3}
\end{align}
Calcular estas derivadas de orden superior de forma explícita resulta tedioso y costoso computacionalmente. La idea de los métodos de Runge-Kutta es aproximar los términos de la serie de Taylor evaluando $f$ en puntos estratégicos dentro del intervalo $[t_n, t_n+h]$, evitando así el cálculo directo de derivadas superiores.

Un método de Runge-Kutta de $s$ etapas tiene la forma general:
\begin{equation}
    y_{n+1} = y_n + h\sum_{i=1}^{s} b_i k_i, \qquad k_i = f\!\left(t_n + c_i h,\; y_n + h\sum_{j=1}^{i-1} a_{ij}\, k_j\right),
\end{equation}
donde los coeficientes $b_i$, $c_i$ y $a_{ij}$ se determinan exigiendo que la fórmula reproduzca la mayor cantidad posible de términos de la serie de Taylor.

\subsubsection*{Derivación del método clásico RK4}

Para el método clásico de cuarto orden ($s=4$), las etapas y la fórmula de avance son:
\begin{align}
    k_1 &= f(t_n,\; y_n), \label{eq:k1}\\
    k_2 &= f\!\left(t_n + \tfrac{h}{2},\; y_n + \tfrac{h}{2}\,k_1\right), \label{eq:k2}\\
    k_3 &= f\!\left(t_n + \tfrac{h}{2},\; y_n + \tfrac{h}{2}\,k_2\right), \label{eq:k3}\\
    k_4 &= f\!\left(t_n + h,\; y_n + h\,k_3\right), \label{eq:k4}\\[4pt]
    y_{n+1} &= y_n + \frac{h}{6}\left(k_1 + 2k_2 + 2k_3 + k_4\right). \label{eq:rk4}
\end{align}
Los pesos $1/6$, $1/3$, $1/3$, $1/6$ coinciden con los de la regla de cuadratura de Simpson: $k_1$ y $k_4$ son pendientes en los extremos del intervalo, mientras que $k_2$ y $k_3$ son pendientes calculadas en el punto medio con aproximaciones sucesivamente más precisas de $y(t_n+h/2)$. Los coeficientes se resumen en el \textbf{tableau de Butcher}:
\begin{equation}
\renewcommand\arraystretch{1.4}
\begin{array}{c|cccc}
0   &     &     &     &     \\
1/2 & 1/2 &     &     &     \\
1/2 &  0  & 1/2 &     &     \\
1   &  0  &  0  &  1  &     \\
\hline
    & 1/6 & 1/3 & 1/3 & 1/6
\end{array}
\end{equation}

\subsubsection*{Verificación del orden de precisión}

Para comprobar que la fórmula (\ref{eq:rk4}) reproduce la serie de Taylor, se expande cada $k_i$ alrededor de $(t_n, y_n)$ usando la fórmula de expansión en dos variables:
\begin{equation}
    f(t+\alpha,\, y+\beta) = f + \alpha f_t + \beta f_y + \frac{\alpha^2}{2}f_{tt} + \alpha\beta\, f_{ty} + \frac{\beta^2}{2}f_{yy} + \mathcal{O}(3),
\end{equation}
donde todas las derivadas se evalúan en $(t_n, y_n)$.

\medskip\noindent
\textbf{Etapa $k_1$:}
\begin{equation}
    k_1 = f.
\end{equation}

\noindent
\textbf{Etapa $k_2$} $\bigl(\alpha = h/2,\;\beta = hf/2\bigr)$:
\begin{equation}
    k_2 = f + \frac{h}{2}(f_t + f\,f_y) + \frac{h^2}{8}(f_{tt} + 2f\,f_{ty} + f^2\!f_{yy}) + \mathcal{O}(h^3).
\end{equation}

\noindent
\textbf{Etapa $k_3$} $\bigl(\alpha = h/2,\;\beta = hk_2/2\bigr)$. Utilizando $k_2 = f + \mathcal{O}(h)$ en los términos de segundo orden:
\begin{equation}
    k_3 = f + \frac{h}{2}(f_t + f\,f_y) + \frac{h^2}{8}(f_{tt} + 2f\,f_{ty} + f^2\!f_{yy}) + \frac{h^2}{4}f_y(f_t + f\,f_y) + \mathcal{O}(h^3).
\end{equation}

\noindent
\textbf{Etapa $k_4$} $\bigl(\alpha = h,\;\beta = hk_3\bigr)$. Utilizando $k_3 = f + \mathcal{O}(h)$ en los términos de segundo orden:
\begin{equation}
    k_4 = f + h(f_t + f\,f_y) + \frac{h^2}{2}(f_{tt} + 2f\,f_{ty} + f^2\!f_{yy}) + \frac{h^2}{2}f_y(f_t + f\,f_y) + \mathcal{O}(h^3).
\end{equation}

\medskip
Calculando la combinación ponderada $k_1 + 2k_2 + 2k_3 + k_4$ (con coeficientes de los términos en $h^0$: $1+2+2+1=6$; en $h^1$: $0+1+1+1=3$; en $h^2$: coeficiente de $(f_{tt}+\ldots)$ es $0+1/4+1/4+1/2=1$; coeficiente de $f_y(f_t+f f_y)$ es $0+0+1/2+1/2=1$):
\begin{align}
    k_1 + 2k_2 + 2k_3 + k_4 &= 6f + 3h(f_t + f\,f_y) \notag\\
    &\quad + h^2\!\Bigl[f_{tt} + 2f\,f_{ty} + f^2\!f_{yy} + f_y(f_t + f\,f_y)\Bigr] + \mathcal{O}(h^3).
\end{align}
Multiplicando por $h/6$:
\begin{equation}
    y_{n+1} = y_n + hf + \frac{h^2}{2}(f_t + f\,f_y) + \frac{h^3}{6}\bigl[f_{tt} + 2f\,f_{ty} + f^2\!f_{yy} + f_y(f_t + f\,f_y)\bigr] + \mathcal{O}(h^4).
\end{equation}
Identificando con las expresiones (\ref{eq:d1})--(\ref{eq:d3}):
\begin{equation}
    y_{n+1} = y_n + h\,y'_n + \frac{h^2}{2}\,y''_n + \frac{h^3}{6}\,y'''_n + \mathcal{O}(h^4),
\end{equation}
lo que coincide con la serie de Taylor hasta el término de orden $h^3$. Extendiendo las expansiones de $k_i$ hasta orden $h^3$ (lo que requiere derivadas parciales de tercer orden de $f$), se puede mostrar que también se reproduce el término $h^4 y^{(4)}/24$, con lo que el \textbf{error local de truncación es $\mathcal{O}(h^5)$} y el \textbf{error global acumulado es $\mathcal{O}(h^4)$}: el método es de \textbf{cuarto orden de precisión}.\cite{Burden2017RungeKutta} \cite{Gutierrez2024Metodos}

\subsubsection*{Extensión a sistemas vectoriales}

Cuando el estado del sistema viene descrito por un vector $\mathbf{y} = (y_1, y_2, \ldots, y_N)^{\!\top}$ que satisface $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$, el método RK4 se aplica de forma idéntica reemplazando escalares por vectores:
\begin{align}
    \mathbf{k}_1 &= \mathbf{f}(t_n,\; \mathbf{y}_n), \\
    \mathbf{k}_2 &= \mathbf{f}\!\left(t_n + \tfrac{h}{2},\; \mathbf{y}_n + \tfrac{h}{2}\,\mathbf{k}_1\right), \\
    \mathbf{k}_3 &= \mathbf{f}\!\left(t_n + \tfrac{h}{2},\; \mathbf{y}_n + \tfrac{h}{2}\,\mathbf{k}_2\right), \\
    \mathbf{k}_4 &= \mathbf{f}\!\left(t_n + h,\; \mathbf{y}_n + h\,\mathbf{k}_3\right), \\[4pt]
    \mathbf{y}_{n+1} &= \mathbf{y}_n + \frac{h}{6}\left(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4\right).
\end{align}
En el caso del péndulo doble, $\mathbf{y} = (\theta_1, \theta_2, \omega_1, \omega_2)^{\!\top}$ y $\mathbf{f} = (\omega_1, \omega_2, f_1, f_2)^{\!\top}$, siendo $f_1$ y $f_2$ las funciones definidas en la sección de Metodología.
